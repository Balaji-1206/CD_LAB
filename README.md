# CD_LAB

This repository contains Compiler Design laboratory experiments implemented using **FLEX (LEX)** and **BISON (YACC)**.

## Repository Structure

- `compiler_design_lab/exp1` — Lexical analyser with symbol table
- `compiler_design_lab/exp2` — Lexical analyser (token recognition)
- `compiler_design_lab/exp3` — Valid arithmetic expression recognition
- `compiler_design_lab/exp4` — Valid variable recognition
- `compiler_design_lab/exp5` — Control structure syntax recognition
- `compiler_design_lab/exp6` — Calculator using LEX and YACC

## How to Use

Each experiment folder contains:
- Source files (`.l`, `.y`, etc.)
- A local `readme.md` with aim, algorithm, compile/run commands, and expected output
- Sample output file(s)

Open the experiment-level `readme.md` for step-by-step execution details.
